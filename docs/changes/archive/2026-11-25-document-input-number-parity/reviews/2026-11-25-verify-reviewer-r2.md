## Findings

### F-01 [critical] `INN-002.S1` Jest test omits Signal Forms `[formField]` binding and bidirectional sync (Constitution Article XI)

**Where:** `projects/medra/ui/src/lib/input-number/input-number.component.spec.ts:348-361`, `docs/changes/document-input-number-parity/specs/input-number/spec.md:20-26`, `docs/changes/document-input-number-parity/tasks.md:8` · `INN-002.S1`, `T003`, Constitution Article XI, Constitution Article V
**Problem:** `Scenario INN-002.S1` specifies **Given** an `InputNumberComponent` with `min` and `max` set to `undefined` or bound via Signal Forms `[formField]` and **Then** "`aria-valuemin` and `aria-valuemax` are omitted when bounds are `undefined`, values are not clamped to `NaN`, and `[formField]` syncs the numeric value bidirectionally", and `T003` explicitly commits to testing both `undefined` `min`/`max` and Signal Forms `[formField]` compatibility in `input-number.component.spec.ts`. The added test (`input-number.component.spec.ts:348-361`) only sets `min`/`max` directly via `fixture.componentRef.setInput(...)`; `@angular/forms/signals` (`form`, `FormField`) and `[formField]` are never imported or mounted in `projects/medra/ui/src/lib/input-number/input-number.component.spec.ts`, and bidirectional synchronization (model -> input and input -> model) is never asserted. Under Constitution Article XI, every test tagged with a scenario ID must assert every Given and Then clause of that scenario. (While `e2e/site/input-number-docs.spec.ts:93-98` types `42` into the Signal Forms demo, it is tagged `INN-001.S1` rather than `INN-002.S1`, checks only view-to-model output, and does not cover Jest unit tests under Constitution Article V / `T003`.)
**Fix:** Update `projects/medra/ui/src/lib/input-number/input-number.component.spec.ts` so `INN-002.S1` (either in the existing test or a companion `INN-002.S1` host test) mounts `<med-input-number [formField]="..." />` using `form()` and `FormField` from `@angular/forms/signals` with unconstrained bounds (`undefined`), asserts `aria-valuemin`/`aria-valuemax` are omitted, verifies typing/stepping updates the signal model without `NaN` clamping, and verifies programmatic signal model updates sync back into the rendered `<input>` value.
