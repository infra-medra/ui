## Router links

Set `routerLink` on a `MenuItem` to point it at a route, as a path (`'/docs/components/menu'`) or as router
commands (`['/docs/components', 'menubar']`). The item renders as a real `<a href>`: a plain click navigates
through the Router without reloading the page, while Ctrl/Cmd+click, middle-click and "copy link" are left
to the browser. `command` still runs, and `routerLink` wins over `url` when an item has both. Links are
resolved from the app root, and a disabled item renders no `href`.

The Router bridge lives in the optional `@medra.dev/ui/router` entry point, so apps that never use `routerLink`
don't need `@angular/router`. Register it once, after `provideRouter(...)`; rendering an item with
`routerLink` without it throws an error that says so:

```ts
import { provideRouter } from '@angular/router';
import { provideMedraMenuRouterLinks } from '@medra.dev/ui/router';

export const appConfig = {
  providers: [provideRouter(routes), provideMedraMenuRouterLinks()],
};
```

`routerLink` is a navigation shortcut, **not authorization**: guard the route itself.
