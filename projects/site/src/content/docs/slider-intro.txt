Slider implements both WAI-ARIA APG slider patterns depending on its `range` input: `false` (the
default) gives a single `role="slider"` thumb bound to a plain `number`; `true` switches to two
independent thumbs bound to a `{ start: number; end: number }` object instead — a runtime shape
switch, not a generic type parameter, the same pattern `DatePicker`'s `selectionMode` uses. Every
pointer listener lives on the track itself, not on the thumbs: pressing anywhere on the track
computes the target position, decides which thumb it belongs to (whichever is closer, in range
mode), moves focus there, and keeps dragging from that same pointer-down — so clicking the bare
track to jump works exactly like grabbing a handle. In range mode the two thumbs can never cross:
dragging one past the other just clamps `start` at `end` (or vice versa) rather than swapping
which thumb is which. There's no `null` value — a thumb always sits at some position, so an
unwritten value defaults to `min` (or `{ start: min, end: max }` in range mode) instead of
rendering without one. Keyboard support covers Arrow keys (by `step`), Page Up/Down (by
`step * 10`), and Home/End (jump to `min`/`max`) on whichever thumb has focus. It implements
`ControlValueAccessor`, so bind it with `[(ngModel)]` or a reactive `formControl`, typed as
`SliderValue` from `@medra.dev/ui` if needed.
