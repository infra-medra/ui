## Global filter

`filterable` shows a search box above the table. By default the text is matched against every column; `globalFilterFields` restricts the match to the listed fields. `filterDelay` sets the debounce in milliseconds (300 by default), and `filterPlaceholder` changes the placeholder. The `filter` output emits the search text and the matching rows, and `globalFilterValue` can be bound two-way to set or read the text.
