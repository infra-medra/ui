DataTable declares its columns as content children — `<med-table-column field="..." header="...">` elements nested directly inside `<med-data-table>` — rather than a `columns` config-array input, the same "children declared in the consumer's own template" shape most composite components in this library follow. Sorting and the global `filterable` search box both run entirely client-side against the `value` array already in memory: clicking a `sortable` column header cycles it through ascending, descending, and back to unsorted, and `aria-sort` tracks whichever state is current. Pagination is a built-in `[paginator]`/`[rows]` pair backed by the same `PaginatorComponent` used elsewhere, not something you compose in yourself. `selectionMode` switches `selection`'s runtime shape — `single` binds one row (or `null`), `multiple` binds a `readonly T[]` and adds a checkbox column whose "select all" applies to every row currently matching the sort and filter, not only the rows on the current page. A `<ng-template>` projected inside a `<med-table-column>` replaces that column's default `row[field]` text rendering when a cell needs custom formatting.
