## Column filters

`columnFilter` on a column adds a funnel button to its header. The button opens a menu with a match mode select, a value control and Apply and Clear buttons; Apply, or Enter in the value control, commits the rule and returns the table to its first page. `filterType` picks the value control and the match modes: `text` (contains, notContains, startsWith, endsWith, equals, notEquals), `numeric` (equals, notEquals, lt, lte, gt, gte) or `date` (dateIs, dateIsNot, dateBefore, dateAfter, compared as calendar days). `filterMatchModes` restricts the offered modes and `filterMatchMode` sets the preselected one. Column rules combine with the global filter, and the `columnFilters` model holds every rule keyed by field, so it can be bound two-way to set or read them.
