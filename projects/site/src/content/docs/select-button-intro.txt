SelectButton renders `options` — the same `SelectOption<T>` shape Select and MultiSelect already use — as a row of connected buttons instead of a dropdown. In its default single-select mode it's a real `role="radiogroup"` of `role="radio"` buttons with roving `tabindex` and arrow-key navigation. Set `multiple` to switch to independent `aria-pressed` buttons inside a plain `role="group"`, each with its own `tabindex="0"` — the bound value type flips accordingly, from `T | null` in single mode to `readonly T[]` in multiple mode. `allowEmpty` (default `true`) governs whether clicking an already-selected option clears it: in single mode, back to `null`; in multiple mode, down to (but never below) one remaining selection once `allowEmpty` is set to `false`. Both modes implement `ControlValueAccessor`, so `[(ngModel)]` or a reactive form control binds to it the same way regardless of which mode is active.
