## Column resize

`resizableColumns` adds a drag handle to each header border so users can change column widths. By default `columnResizeMode` is `fit`: dragging a border moves width between the dragged column and its right neighbour, so the table keeps its total width. Neither column shrinks below 40px, and the last visible column has no handle because it has no neighbour to trade with. The `colResize` output emits the resized header element and the width change in pixels once the drag ends.
