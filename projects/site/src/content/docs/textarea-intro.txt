Textarea (`textarea[medTextarea]`) is an attribute directive, not a component — it applies straight to a native `<textarea>` and reuses InputText's own field styling, the same `inputTextVariants` CVA, so borders, padding, the focus ring, and the `invalid`/`disabled` states look identical between the two. By default it adds one behavior of its own: a `resize-y` class, which turns on the browser's native vertical drag-resize handle — width and starting height still come from the native `rows` attribute and your own CSS. `size` (`sm`/`default`/`lg`) and `invalid` control the same visual variants InputText exposes. It implements `ControlValueAccessor` over the native `(input)` event, so `[(ngModel)]` or a reactive form control works exactly like it does on InputText.
