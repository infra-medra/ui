ConfirmDialogService is a thin, opinionated layer over `DialogService` — `confirm()` supplies a
built-in content component (icon + message + Accept/Reject) instead of every caller hand-rolling
its own confirmation dialog. `severity` (`info`/`success`/`warn`/`danger`/…) picks the icon and,
unless you set `acceptSeverity` yourself, the Accept button's color too — a destructive
confirmation gets a destructive-colored button without saying so twice. The returned `DialogRef`'s
`closed$` resolves `true` (Accept), `false` (Reject), or `undefined` (dismissed via Esc, the
backdrop, or the header close button) — use this when the action warrants blocking the whole
page; reach for ConfirmPopup instead for a lighter, anchored "are you sure?" next to the control
that triggered it.
