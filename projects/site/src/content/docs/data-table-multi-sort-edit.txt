## Multi-column sort and inline editing

`sortMode="multiple"` layers `multiSortMeta` on top of the existing single-column sort: a plain
click on a header replaces the whole multi-sort with just that column, Shift+click adds or cycles
that column within the existing array while keeping the others — the same convention spreadsheets
already use, so there's no extra input needed to configure the modifier key.

`editMode="cell"` opts a column into inline editing: add `editable` to `<med-table-column>` plus a
second, named template — `<ng-template #editTemplate let-row let-onSave="onSave"
let-onCancel="onCancel">` — alongside its normal display template. Double-clicking a cell swaps in
the edit template; the template's own input decides when to call `onSave(value)` or `onCancel()`,
and the table surfaces the result through `editComplete`/`editCancel`.
