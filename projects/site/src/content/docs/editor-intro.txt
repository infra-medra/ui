Editor is a minimal rich text editor: a native `contenteditable` region paired with a fixed formatting toolbar (a heading-level select, bold, italic, underline, link insertion, bullet and numbered lists, undo/redo) — not a wrapper around a third-party engine like Quill or ProseMirror. Its bound value, through `[(ngModel)]` or a reactive form control under the same `ControlValueAccessor` shape every MedraUi input uses, is a plain HTML string, and that string is run through Angular's `DomSanitizer` on every write in both directions — a paste from an untrusted source and an outgoing model update are both sanitized before either one reaches the DOM or your model, so a pasted `<script>` tag never survives. Formatting is driven by the browser's own `execCommand`/`queryCommandState` APIs — formally deprecated, but still the only cross-browser way to drive `contenteditable` formatting without pulling in a heavy dependency — which is why the toolbar is fixed today rather than configurable through an input. The pressed look on bold, italic, and underline reflects real editor state via `queryCommandState`; the list buttons don't get the same indicator, because querying list state that way is unreliable across browsers, even though the commands themselves still work correctly. The heading `<select>` resets back to its placeholder after applying a level — same "reliable command, unreliable state query" limitation as the list buttons — and the link button opens a small overlay asking for a URL rather than driving `execCommand('createLink')` directly from the toolbar.
