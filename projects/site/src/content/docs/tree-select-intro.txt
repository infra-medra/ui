TreeSelect is a Select-style combobox trigger that opens a `TreeComponent` picker in a floating panel instead of a flat option list — `options` takes the exact same `TreeNode[]` shape (`{ label, icon?, children?, expanded?, selectable? }`) Tree itself uses. It implements `ControlValueAccessor`, so `[(ngModel)]`/`formControl` binds directly to the selected `TreeNode` object itself, not to some separate primitive id or value field — there isn't one. Either a branch or a leaf node can be picked, unless it carries `selectable: false`; clicking any pickable row closes the panel immediately, there's no separate "confirm" step. This first version only supports picking one node — no multiple/checkbox mode — and the panel offers no lazy-loading hook, so `options` needs the whole hierarchy up front the same way Tree does.
