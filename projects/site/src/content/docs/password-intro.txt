Password wraps a real `<input type="password">`, swapped only to `type="text"` while its reveal
button — shown when `toggleMask` is enabled — is toggled on; there's no custom masked-text
reimplementation underneath. The bound value is a plain string, the same as `InputText`. `showClear`
adds an inline button that resets the value to an empty string, shown only once there's something
to clear. Setting
`feedback` opens a small, non-interactive strength-meter panel on focus: the live value is tested
against `strongRegex` first (default: uppercase + lowercase + digit + symbol, 8+ characters),
falling back to `mediumRegex` (default: uppercase + lowercase + digit, 6+ characters), then `weak`
for anything else non-empty — it never evaluates both and picks the stronger match, so supplying a
`strongRegex` looser than your own `mediumRegex` is a configuration mistake this won't catch for
you. The feedback panel never takes real DOM focus away from the input, so it closes on the
input's own blur instead of needing separate outside-click wiring. It implements
`ControlValueAccessor`, so bind it with `[(ngModel)]` or a reactive `formControl` like any other
MedraUi input.
