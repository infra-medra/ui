# MedraUi

## Language policy

All text inside this repository's source code must be written in **English**:
code comments, TSDoc, identifiers, test descriptions (`describe`/`it`),
console/log messages, generated docs, CSS comments, changelog entries — every
piece of text that lives in a source file under this repo.

The only exception is `roadmap/`: the in-repo hub for technical decisions,
roadmap, backlog, parity audits, and the design token catalog, which is written
in Portuguese. Everywhere else in the repo — `projects/`, `e2e/`, or any other
source file — English is mandatory.

## Documentation

Project documentation lives in two places:

- **`roadmap/`** — decisions, roadmap, backlog, component
  checklists, and the design token catalog for this project. Written in
  Portuguese (see exception above).
- **Everywhere else** — code-level documentation (TSDoc, READMEs for
  packages, e2e docs) stays in English, next to the code it describes.
