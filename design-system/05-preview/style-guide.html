Foundations — Shadows & Elevation

The missing shadow-overlay-md — fixed 2026-08-19

Before

ImageCompare's handle & SpeedDial's action button referenced shadow-overlay-md

The token didn't exist in @theme — Tailwind generated nothing, so both elements silently rendered with no shadow at all.

After (applied)

--shadow-overlay-md, now defined

Value interpolated between -sm/-lg following Tailwind's own default box-shadow progression, not a freehand pick. See 00-audit-report.md, action 1.
